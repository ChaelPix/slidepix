# SlidePix

Open `*.slidepix.json` files as visual presentations in VS Code or Cursor.

- Visual slide editor with text, Markdown, LaTeX, code, media, and shapes
- Git-friendly JSON source and sibling asset directory
- PDF and PNG export
- Fullscreen presentation and presenter console
- Read-only MCP tools for AI review

Run **SlidePix: Create Deck** from the Command Palette to begin.
